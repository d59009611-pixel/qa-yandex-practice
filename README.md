# QA Practice Project (в стиле Яндекс)

## Описание
В данном репозитории представлены результаты ручного тестирования веб-приложения SauceDemo.

## Область тестирования
 Авторизация (логин)
 Каталог товаров
 Корзина
 Оформление заказа (checkout)

## Виды тестирования
 Функциональное тестирование
 UI тестирование
 Негативное тестирование

## Что содержится в репозитории
 checklist.md — чек-лист проверок
 test-cases.md — тест-кейсы
 bug-reports.md — найденные баги

## Инструменты
 Ручное тестирование (manual testing)

## Цель проекта
Закрепить базовые навыки тестирования и продемонстрировать умение:
 находить баги
 писать тест-кейсы
 структурировать тестовую документацию
