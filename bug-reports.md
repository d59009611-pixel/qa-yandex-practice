# Bug Report – Login System

## BUG-01: Не входит без логина и пароля
**Серьёзность:** Medium

### Описание
Если нажать кнопку Login без ввода логина и пароля, появляется некорректное или непонятное сообщение об ошибке.

### Шаги воспроизведения
1. Открыть страницу входа
2. Оставить поля username и password пустыми
3. Нажать кнопку Login

### Фактический результат
Появляется ошибка, но сообщение непонятное или некорректное

### Ожидаемый результат
Сообщение: "Введите логин и пароль"

---

## BUG-02: После ошибки вход не работает корректно
**Серьёзность:** Medium

### Описание
После ошибки входа с пустыми полями система может не пускать пользователя даже при правильном вводе данных.

### Шаги воспроизведения
1. Открыть страницу входа
2. Нажать Login с пустыми полями
3. Получить ошибку
4. Ввести корректные username и password
5. Снова нажать Login

### Фактический результат
Система не выполняет вход или остаётся ошибка

### Ожидаемый результат
Пользователь успешно входит в систему

---

## BUG-03: Некорректная работа полей ввода
**Серьёзность:** High

### Описание
При вводе и редактировании текста в полях username/password наблюдается нестабильная работа (лаги, сбои ввода).

### Шаги воспроизведения
1. Ввести текст в поле username или password
2. Удалить символ
3. Снова начать ввод

### Фактический результат
Поле работает нестабильно, возможны лаги или некорректный ввод

### Ожидаемый результат
Поле должно стабильно принимать и изменять ввод
